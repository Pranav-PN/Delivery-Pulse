> **A Probability and Statistical Learning Study of Food-Delivery Performance in RStudio**  
> Formulates food-delivery Estimated Time of Arrival (ETA) breaches as a Bernoulli trial, fits parametric distributions to transit duration, conducts rigorous hypothesis testing with FDR adjustments, and trains probabilistic classifiers (Logistic Regression & Naive Bayes) with dispatch triage optimization.

---

## 📌 Project Overview

In quick-commerce and on-demand food logistics, last-mile fulfillment is both the most cost-intensive and the most volatile stage of the delivery supply chain. Environmental disruptions (fog, rain, sandstorms), peak traffic congestion, multi-order stacking, and courier characteristics frequently result in delivery delays exceeding promised customer windows (> 30 minutes).

**DeliveryPulse** approaches delivery delay as a random Bernoulli event $Y \in \{0, 1\}$. By synthesizing probability theory (Clopper-Pearson exact CIs, Wilson score intervals, Gamma vs. Lognormal MLE fitting, Binomial batch risk) and statistical learning (Logistic Regression with IRLS, Naive Bayes), this project explains the fundamental drivers of delay and provides an operational dispatch triage engine that captures **61.84% of all late deliveries** by intervening on only the **top 20%** highest-risk in-flight orders.

## 🔬 Statistical & Machine Learning Methodology

### 1. Data Cleaning & Spatial Engineering (`01_clean.R`)
- Filtered anomalous GPS coordinate pairs (distance $= 0$ km or $> 50$ km) and imputed missing values across modeling regressors.
- Computed great-circle surface transit distances via `geosphere::distHaversine()`.
- Established discrete binary outcome $Late \in \{0, 1\}$ (threshold: $> 30$ minutes).
- **Final Sample Size:** 41,222 valid observations.

### 2. Probability Modeling & Distribution Fitting (`02_eda_distributions.R`)
- **Empirical Delay Rate:** $p = 30.62\%$ ($12,622$ late deliveries).
- **Confidence Intervals (95%):**
  - Clopper-Pearson Exact CI: $[0.3017, 0.3107]$
  - Wilson Score CI: $[0.3018, 0.3107]$
- **Parametric Fitting via MLE:**
  - **Gamma Distribution:** $\text{shape} = 7.940, \text{rate} = 0.299$ ($\text{AIC} = \mathbf{298,377.9}$)
  - **Lognormal Distribution:** $\text{meanlog} = 3.215, \text{sdlog} = 0.366$ ($\text{AIC} = 299,176.8$)
  - *Result:* Gamma distribution minimizes information loss by $\Delta \text{AIC} = 798.9$.
- **Batch Risk Simulation:** In a random batch of $n = 50$ orders, the probability that $\ge 40\%$ ($\ge 20$ orders) are late is $P(K \ge 20) = \mathbf{10.11\%}$.

### 3. Hypothesis Testing Suite (`03_hypothesis_tests.R`)
- **Welch Two-Sample $t$-Tests (Continuous Predictors):**
  - **Distance ($km$):** Mean On-Time $= 8.73$ km vs. Mean Late $= 12.19$ km ($t = 61.71, p < 10^{-4}, 95\% \text{ CI: } [3.35, 3.57]$).
  - **Rider Age:** Mean On-Time $= 28.76$ yrs vs. Mean Late $= 31.54$ yrs ($t = 47.48, p < 10^{-4}$).
  - **Rider Rating:** Mean On-Time $= 4.73$ vs. Mean Late $= 4.41$ ($t = -80.17, p < 10^{-4}$).
- **Chi-Square Tests of Independence & Cramer's V (BH-Adjusted):**
  - `Road_traffic_density`: $\chi^2 = 6,031.7, V = \mathbf{0.3825}, p_{\text{adj}} < 10^{-4}$ (Strongest categorical driver)
  - `multiple_deliveries`: $\chi^2 = 5,886.1, V = \mathbf{0.3779}, p_{\text{adj}} < 10^{-4}$
  - `Weatherconditions`: $\chi^2 = 2,438.8, V = \mathbf{0.2432}, p_{\text{adj}} < 10^{-4}$
  - `Type_of_order`: $\chi^2 = 0.88, V = 0.0046, p_{\text{adj}} = \mathbf{0.8300}$ (Statistically Insignificant)

### 4. Correlation Analysis (`04_correlation.R`)
- Pearson correlation between distance and delivery time: $r = \mathbf{+0.3220}$ ($p < 10^{-4}$).
- Pearson correlation between rider ratings and delivery time: $r = \mathbf{-0.3597}$ ($p < 10^{-4}$).
- Point-biserial correlation between distance and $Late$: $r_{pb} = \mathbf{+0.2837}$ ($p < 10^{-4}$).
- Inter-predictor correlations remained $|r| \le 0.115$, confirming absence of multicollinearity.

### 5. Probabilistic Machine Learning (`05_models.R`)
- Stratified 70/30 split using `caTools::sample.split` ($N_{\text{train}} = 28,855$, $N_{\text{test}} = 12,367$).
- **Logistic Regression (GLM with Logit Link via IRLS):**
  - `distance_km`: $\text{OR} = 1.1575$ (each additional km increases delay odds by $15.75\%$, $p < 10^{-16}$).
  - `Delivery_person_Age`: $\text{OR} = 1.1325$ (each year of age increases delay odds by $13.25\%$, $p < 10^{-16}$).
  - `Delivery_person_Ratings`: $\text{OR} = 0.0051$ (higher ratings dramatically decrease delay odds, $p < 10^{-16}$).
  - `multiple_deliveries1`: $\text{OR} = 1.5350$ ($53.5\%$ higher delay odds for stacked deliveries).
- **Naive Bayes Classifier (`e1071`):** Applied Bayes' Theorem with Gaussian and multinomial feature likelihoods.

### 6. Held-Out Evaluation & Dispatch Triage (`06_evaluate.R`)

| Metric | Logistic Regression | Naive Bayes Classifier |
|:---|:---:|:---:|
| **Test Accuracy** | **88.42%** | **88.61%** |
| **Sensitivity (Recall)** | **75.94%** | 69.82% |
| **Specificity** | 93.93% | **96.90%** |
| **ROC / AUC** | **0.9386** | **0.9397** |

#### Operational Triage Lift
If an operations control center can intervene on only the **top 20%** most at-risk orders ($2,474$ orders out of $12,367$), the logistic regression model successfully captures **2,342 out of 3,787 actually late deliveries (61.84%)**, providing a **3.09× operational efficiency lift** over random auditing.

## 🚀 Running the Project

### Prerequisites
Install R ($\ge 4.2$) and the required R libraries:
```r
install.packages(c("geosphere", "fitdistrplus", "ggplot2", "caTools", 
                   "e1071", "pROC", "shiny", "shinydashboard", "DT", "plotly"))
```

### Reproducing Analysis (Scripts 01 to 06)
Run all scripts sequentially in R or via terminal:
```bash
Rscript scripts/01_clean.R
Rscript scripts/02_eda_distributions.R
Rscript scripts/03_hypothesis_tests.R
Rscript scripts/04_correlation.R
Rscript scripts/05_models.R
Rscript scripts/06_evaluate.R
```

### Launching the DeliveryPulse Companion Shiny Dashboard
Launch the interactive web application locally:
```bash
Rscript -e "shiny::runApp('app', port=3838, host='127.0.0.1')"
```
Open **[http://127.0.0.1:3838](http://127.0.0.1:3838)** in your browser to access:
- **Command Center:** Real-time KPI counters, predicted probability histogram, and predictor importance rankings.
- **Dispatch Queue:** In-flight order table sorted by predicted delay probability with color-coded risk tiers.
- **Order Explorer:** Interactive scenario simulator with what-if sliders and attribution waterfall plots.
- **Model & Reliability:** Performance evaluation tables and ROC curves.
